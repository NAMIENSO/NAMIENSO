# 診断カテゴリ

全カテゴリで、前後文脈・場面効果・提供設定を根拠にする。単発の語、頻度、平均文長だけで問題認定しない。重複する指摘をまとめ、最優先5件程度を選ぶ。

| カテゴリ | 確認する編集上の問題 | 残す条件・推奨対応 |
|---|---|---|
| redundant_explanation | 台詞や動作ですでに伝わる意味を地の文で説明し、さらに感情要約するshow→tell→tell again | 解釈や情報が更新されるなら残す。重複部分だけ省く |
| reader_trust | 読者が理解できる内容を「つまり」「彼は理解した」等で再説明して読む流れを止める | 推理の誤り・人物の認識変化・意図的皮肉なら有効。語を禁じず再説明の役割を見る |
| subject_reanchoring | 短い区間で主体を置き直し続け、台詞→主体→説明を定型化する | 多人数の発話・視点切替・動作主混同を防ぐ主体は必須。省略して誰か分からなくなるなら残す |
| generic_reaction | 誰にでも当てはまる反応が続き、人物差や感情の段階が伝わらない | 目を見開く・息を呑む・苦笑等の一度の自然な反応は問題ではない。既存の癖・目的・関係性・台詞・身体行動から選ぶ |
| abstract_fallback | 感情・空気・何か・違和感等だけで具体的に何が変わったか掴めない | 視点人物がまだ言語化できない、伏線を隠す等の意図なら残す。既存の対象や観察へ戻す |
| connective_overuse | 文間の論理関係を毎回明示し、溜めや含意を薄める | 因果が誤読される箇所・人物の論理的口調は残す。省略で強くなる接続だけ見直す |
| summary_ending | 場面末尾で直前の意味を再要約し、余韻を閉じすぎる | 語り手の癖・予告・皮肉・読者への約束なら有効。まとめを外して場面が成立するか検討する |
| rhythm_uniformity | 文・段落・台詞・文末・改行・説明と会話の交互配置が場面の目的に対して単調 | 統計的均一さだけでは悪くない。切迫した短文連打や儀礼的反復は場面効果を優先する |
| dialogue_interchangeability | 人物を入れ替えても語彙・思考・感情の表し方が同じで対立や関係が見えない | 同調・儀式・模倣を意図する台詞は残す。人物設定がなければ差別化の可能性を指摘するだけにする |
| safe_prose | 意味は通るが、視点人物の選択や場面に固有の観察が伝わらない | 平明さが目的なら問題ではない。具体化・省略・人物化・情報順・リズム・既存の判断を優先し、無理な比喩を足さない |
| author_voice_drift | 作者参照と比べ、語りの距離・省略・ユーモア等が場面差で説明できず失われている | 作者自身の複数の声を認める。参照1段落だけで作者の普遍的傾向と断定しない |

## 人物声の具体的な観点

語彙、一人称、呼称、文末、思考方法、感情の示し方、情報量、冗談、攻撃性、遠慮、設定された身分・年齢を見る。年齢や身分からステレオタイプの口調を自動生成しない。提供された台詞・人物設定から修正案を選ぶ。

## 確信度と優先度

highは同じ意味の明確な二重説明等、mediumは場面意図に基づく複数の解釈がありうる判断、lowは前後文脈・設定不足の判断。これは編集提案の根拠であり生成元の推定ではない。必要ならnotice/review/strong_reviewで読者理解・人物声・場面効果への影響を示す。語句数や記号数から自動severityを決めない。
